# Урок 13 · Домашнее задание

Тема: ссылки и обновление данных без мутации.

1. Откройте `index.html` в браузере. Внизу страницы и в консоли (F12) работает автопроверка.
2. Пишите код в `script.js`. После каждой функции обновляйте страницу.
3. Цель — 7 из 7 ✅ и письменный ответ на вопрос 8 в конце `script.js`.

| № | Функция | Что сделать |
|---|---|---|
| 1 | `addTask(tasks, title)` | Новая задача `{ id, title, done: false }`, id = последний id + 1 |
| 2 | `deleteTask(tasks, id)` | Удалить по id |
| 3 | `toggleDone(tasks, id)` | Переключить `done` |
| 4 | `renameTask(tasks, id, title)` | Новое название |
| 5 | `sortByTitle(tasks)` | Отсортированный **новый** массив |
| 6 | `moveUser(user, city)` | Поменять вложенный `address.city` |
| 7 | `addTag(user, tag)` | Добавить в вложенный `tags` |
| 8 | вопрос | Почему `{ ...user }` не защищает `user.tags`? |

Если видите ❌ «Мутация!» — функция меняет входные данные. Используйте spread, `filter` или `map`.
