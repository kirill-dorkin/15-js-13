Если здесь пусто — в script.js ошибка. Откройте консоль: F12 → Console.

ЗАДАНИЯ

1. Кнопка «Добавить» — addTask(tasks, task)

Вернуть новый список: все старые задачи + task в конце.

2. Кнопка «✕» — deleteTask(tasks, id)

Вернуть новый список без задачи с этим id.

3. Кнопка «✓» — toggleDone(tasks, id)

Вернуть новый список, где у одной задачи done стало противоположным: true ↔ false.

Подсказка
Противоположное значение: !task.done

4. Кнопка «✎» — renameTask(tasks, id, title)

Вернуть новый список, где у одной задачи новое название title.

5. Вопрос письменно

Почему в addTask нельзя написать tasks.push(task)? Ответ 1–2 предложения — комментарием в конце script.js.
