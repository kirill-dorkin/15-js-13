1

Кнопка «Добавить»

⏳

Вернуть новый список: все старые задачи + task в конце.

addTask(tasks, task)

[ Купить хлеб, Сделать домашку ]
→
ДОЛЖНО СТАТЬ
[ Купить хлеб, Сделать домашку, Новая ]

2

Кнопка «✕»

⏳

Вернуть новый список без задачи с этим id.

deleteTask(tasks, id)
БЫЛО
[ Купить хлеб, Сделать домашку ]  ✕ у хлеба
→
ДОЛЖНО СТАТЬ
[ Сделать домашку ]
Подсказка
filter

3

Галочка

⏳

Вернуть новый список, где у одной задачи done стало противоположным: true ↔ false.

toggleDone(tasks, id)
БЫЛО
☐ Купить хлеб  (done: false)
→
ДОЛЖНО СТАТЬ
☑ Купить хлеб  (done: true)
Подсказка
map + { ...task, done: !task.done }
