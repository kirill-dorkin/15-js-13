ЗАДАНИЯ

1

«Добавить» задачу

⏳

Зачем: новая задача в конце списка. id = id последней задачи + 1 (если список пуст — 1), done: false.

addTask(tasks, title) → новый массив
БЫЛО: 3 задачи, последний id 3
title = "Новая"
→
В КОНЦЕ НОВОГО МАССИВА
{ id: 4, title: "Новая", done: false }
Подсказка
Последний элемент: tasks[tasks.length - 1]
Пустой список: tasks.length === 0

2

«✕» — удалить

⏳

Зачем: новый список без задачи с этим id.

deleteTask(tasks, id) → новый массив
Подсказка
filter

3

Галочка — выполнено / нет

⏳

Зачем: у одной задачи done меняется на противоположное. Остальные задачи — те же объекты.

toggleDone(tasks, id) → новый массив
Подсказка
map + { ...task, done: !task.done }

4

«✎» — переименовать

⏳

Зачем: у одной задачи новый title, id и done сохраняются.

renameTask(tasks, id, title) → новый массив

5

«А→Я» — сортировка

⏳

Зачем: отсортировать по названию. Ловушка: sort меняет исходный массив!

sortByTitle(tasks) → новый массив
Подсказка
Сначала копия массива, потом sort.
Сравнение строк: a.title.localeCompare(b.title)

6

«Переехать» — сменить город

⏳

Зачем: город лежит внутри user.address — вложенный объект. Копируем оба уровня.

moveUser(user, city) → новый объект
БЫЛО
address: { city: "Бишкек", street: "Чуй 1" }
→
ВЕРНУТЬ (city = "Ош")
address: { city: "Ош", street: "Чуй 1" }

7

«+ Тег»

⏳

Зачем: теги — массив внутри user. Нужен новый user с новым массивом tags.

addTag(user, tag) → новый объект
БЫЛО
tags: ["js"]
→
ВЕРНУТЬ (tag = "react")
tags: ["js", "react"]
