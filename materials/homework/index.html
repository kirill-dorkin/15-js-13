ЗАДАНИЯ

  1. addTask(tasks, title) — новая задача { id, title, done: false }, id = последний id + 1.
  2. deleteTask(tasks, id) — удалить по id.
  3. toggleDone(tasks, id) — переключить done.
  4. renameTask(tasks, id, title) — новое название.
  5. sortByTitle(tasks) — новый массив по алфавиту, исходный не трогаем.
  6. moveUser(user, city) — поменять user.address.city (вложенный объект).
  7. addTag(user, tag) — добавить тег в user.tags.
