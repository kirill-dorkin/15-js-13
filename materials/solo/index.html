Самостоятельно · музыкальный плейлист

Тот же приём, что в корзине, но с песнями. Кнопки плеера вызывают функции из script.js. Напишите функции — и плеер заработает. Цель: все задания ✅.

ШАГ 1Откройте script.js
ШАГ 2Напишите функцию по заданию ниже
ШАГ 3Сохраните и обновите страницу (F5)
ШАГ 4Нажмите кнопку в плеере и проверьте ✅

Нажмите любую кнопку. Здесь появится, что сделала функция.

ЗАДАНИЯ

1

Кнопка «Добавить»

⏳

Зачем: пользователь добавил песню. Нужен новый плейлист с этой песней в конце.

addSong(playlist, song) → новый массив
БЫЛО
[ Gulzada, Night City, Ala-Too ]
→
ВЕРНУТЬ (song = Tengri)
[ Gulzada, Night City, Ala-Too, Tengri ]
Подсказка
Как addToCart в корзине, только песню копировать не нужно:
[...старыйМассив, новыйЭлемент]

2

Кнопка «✕»

⏳

Зачем: пользователь удалил песню. Нужен новый плейлист без песни с этим id.

removeSong(playlist, id) → новый массив
БЫЛО: id = 1
[ Gulzada, Night City, Ala-Too ]
→
ВЕРНУТЬ
[ Night City, Ala-Too ]
Подсказка
filter: оставляем всех, у кого id не равен удаляемому.

3

Кнопка «♥» — лайк

⏳

Зачем: лайк добавляет +1 к likes у одной песни. Остальные песни не меняются.

likeSong(playlist, id) → новый массив
БЫЛО: id = 3
Ala-Too likes: 7
→
ВЕРНУТЬ
Ala-Too likes: 8 (остальные как были)
Подсказка
map: нужная песня → { ...song, likes: song.likes + 1 }
остальные → song как есть

4

Кнопка «☆» — сохранить

⏳

Зачем: звёздочка включает и выключает «сохранено». true → false, false → true.

toggleSaved(playlist, id) → новый массив
БЫЛО: id = 2
Night City saved: true
→
ВЕРНУТЬ
Night City saved: false
Подсказка
То же, что лайк, только поле saved: !song.saved

5

Бонус: ползунок громкости

⏳

Зачем: громкость лежит внутри settings.player. Это вложенный объект — копировать нужно оба уровня.

setVolume(settings, volume) → новый объект
БЫЛО
{ theme: "dark",
  player: { volume: 50, shuffle: false } }
→
ВЕРНУТЬ (volume = 80)
{ theme: "dark",
  player: { volume: 80, shuffle: false } }
Подсказка
{ ...settings, player: { ...settings.player, volume } }
