Нажмите любую кнопку. Здесь появится, что сделала функция.

Главное правило: функция не меняет старую корзину, а возвращает новую. Магазин сам заменит старую корзину на новую. Так работает каждая кнопка в React.

ЗАДАНИЯ · пишем по порядку

1

Кнопка «В корзину»

⏳

Зачем: покупатель нажал «В корзину» у товара. Нужна новая корзина, в которой в конце лежит этот товар с количеством 1.

addToCart(cart, product) → новый массив
БЫЛО: cart
[ Чай qty:1, Кофе qty:2 ]
→
ВЕРНУТЬ (product = Сок)
[ Чай qty:1, Кофе qty:2, Сок qty:1 ]
Подсказка
// новый массив: всё старое + новый товар в конце
return [...cart, новыйТовар];
// новый товар = копия product + qty: 1
{ ...product, qty: 1 }

2

Кнопка «✕» — убрать из корзины

⏳

Зачем: покупатель передумал. Нужна новая корзина без товара с этим id.

removeFromCart(cart, id) → новый массив
БЫЛО: cart, id = 2
[ Чай qty:1, Кофе qty:2 ]
→
ВЕРНУТЬ
[ Чай qty:1 ]
Подсказка
// filter оставляет тех, для кого условие true.
// Оставляем всех, у кого id НЕ равен удаляемому:
cart.filter((item) => item.id !== id)

3

Кнопка «+» — ещё одну штуку

⏳

Зачем: покупатель хочет 3 кофе вместо 2. Нужна новая корзина, где у одного товара qty больше на 1, а остальные товары не тронуты.

increaseQty(cart, id) → новый массив
БЫЛО: cart, id = 2
[ Чай qty:1, Кофе qty:2 ]
→
ВЕРНУТЬ
[ Чай qty:1, Кофе qty:3 ]
Подсказка
// map проходит по всем товарам и собирает новый массив
cart.map((item) => {
  if (item.id !== id) {
    return item;              // чужой товар — как есть
  }
  return { ...item, qty: ??? }; // нужный — новый объект
});

4

Кнопка «−10%» — скидка в каталоге

⏳

Зачем: менеджер снижает цену одного товара. Нужен новый каталог, где у товара новая цена. Тот же приём, что в задании 3.

changePrice(catalog, id, price) → новый массив
БЫЛО: id = 1, price = 162
[ Чай 180, Кофе 250, Сок 150 … ]
→
ВЕРНУТЬ
[ Чай 162, Кофе 250, Сок 150 … ]
Подсказка
catalog.map((product) =>
  product.id === id ? { ...product, price } : product
);
