ЗАДАНИЯ

1. Кнопка «В корзину» — addToCart(cart, product)

Вернуть новую корзину: все старые товары + product в конце.

Было [Чай, Кофе] → стало [Чай, Кофе, Сок]

Подсказка
return [...cart, product];

2. Кнопка «✕» — removeFromCart(cart, id)

Вернуть новую корзину без товара с этим id.

Было [Чай, Кофе], ✕ у Кофе → стало [Чай]

Подсказка
filter — оставляем всех, у кого id не равен удаляемому:
return cart.filter((item) => item.id !== id);

3. Кнопка «+» — increaseQty(cart, id)

Вернуть новую корзину, где у одного товара qty на 1 больше. Остальные — как были.

Было [Чай ×1, Кофе ×2], + у Кофе → стало [Чай ×1, Кофе ×3]

Подсказка
map — нужный товар меняем на новый объект, остальные возвращаем как есть:
return cart.map((item) =>
  item.id === id ? { ...item, qty: item.qty + 1 } : item
);
