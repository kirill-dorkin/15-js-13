2Сохраняем и обновляем эту страницу — F5

ЗАДАНИЯ

1

Кнопка «В корзину»

⏳

Вернуть новую корзину: все старые товары + product в конце.

addToCart(cart, product)
БЫЛО
[ Чай, Кофе ]
→
ДОЛЖНО СТАТЬ
[ Чай, Кофе, Сок ]
Подсказка
return [...cart, product];

2

Кнопка «✕»

⏳

Вернуть новую корзину без товара с этим id.

removeFromCart(cart, id)
БЫЛО
[ Чай, Кофе ]  ✕ у Кофе
→
ДОЛЖНО СТАТЬ
[ Чай ]
Подсказка
filter оставляет тех, у кого условие true.
Оставляем всех, у кого id не равен удаляемому:

return cart.filter((item) => item.id !== id);

3

Кнопка «+»

⏳

Вернуть новую корзину, где у одного товара qty больше на 1. Остальные — как были.

increaseQty(cart, id)
БЫЛО
[ Чай ×1, Кофе ×2 ]  + у Кофе
→
ДОЛЖНО СТАТЬ
[ Чай ×1, Кофе ×3 ]
Подсказка
map проходит по всем товарам.
Нужный товар → новый объект, остальные → как есть:

return cart.map((item) =>
  item.id === id ? { ...item, qty: item.qty + 1 } : item
);
