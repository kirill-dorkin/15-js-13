Урок 13 · Корзина MiniShop

Пишем вместе. Каждая функция возвращает новые данные и не меняет входные.

ЗАДАНИЯ

  1. addToCart(cart, product) — добавить товар с qty: 1 в конец.
  2. removeFromCart(cart, id) — убрать товар по id.
  3. increaseQty(cart, id) — увеличить qty на 1 у одного товара.
  4. changePrice(catalog, id, price) — новая цена одного товара.
  5. Бонус: addOrIncrease(cart, product) — есть в корзине → qty + 1, нет → добавить.
