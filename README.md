# JavaScript · Урок 13 — Ссылки и обновление данных

Интерактивная презентация (27 слайдов) + практика: https://15-js-13.vercel.app

- `index.html` — презентация. Клавиши: ← → слайды, Пробел — следующий шаг схемы памяти, G — оглавление, N — заметки, T — тема, F — полный экран.
- `materials/joint` — практика вместе: магазин в консоли, 8 шагов, 25 мин. Сценарий для преподавателя — `teacher/JOINT-GUIDE.md`.
- `materials/solo` — самостоятельная (плеер), 3 функции, 15 мин.
- `materials/homework` — домашнее задание (список задач).
- `materials/SUMMARY.md` — шпаргалка: все понятия и исключения урока.
- `teacher/` — решения.

В каждой папке практики: `index.html` (только подключает скрипт) и `script.js`. Результат — в консоли браузера (F12 → Console): под каждой функцией уже есть `console.log` «Новая» и «Старая» и комментарий «Ожидается». Шаги 1–4 повторяют уроки 1–12 (функции, шаблонные строки, условия, forEach, for...of, find/some), шаги 5–7 — новая тема, шаг 8 — сценарий из всех функций.
