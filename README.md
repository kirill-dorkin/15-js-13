# JavaScript · Урок 13 — Ссылки и обновление данных

Интерактивная презентация (27 слайдов) + практика: https://15-js-13.vercel.app

- `index.html` — презентация. Клавиши: ← → слайды, Пробел — следующий шаг схемы памяти, G — оглавление, N — заметки, T — тема, F — полный экран.
- `materials/joint` — практика вместе (магазин), 20 мин.
- `materials/solo` — самостоятельная (музыкальный плеер), 15 мин.
- `materials/homework` — домашнее задание (список задач).
- `materials/SUMMARY.md` — шпаргалка: все понятия и исключения урока.
- `teacher/` — решения.

В каждой папке практики открыть `index.html` — там мини-приложение, кнопки которого вызывают функции из `script.js`. Пока функция пустая, кнопка не работает и страница объясняет почему. Под приложением — задания с «было → стало», подсказками и автопроверкой ✅/❌/⏳ (ловит мутацию входных данных).
